## Getting Started

Create package.json

```bash
npm init -y
```

Install Typescript as devDependencies

```bash
npm install -D typescript
```

Create tsconfig.json and configure

```bash
tsc --init
```

Install Express, mongoose etc

```bash
npm install express mongoose zod jsonwebtoken cors dotenv

```

Install types/express + etc

```bash
npm install  @types/express @types/cors @types/dotenv @types/jsonwebtoken --save-dev
```

Install ts-node-dev

```bash
npm i ts-node-dev --save-dev
```

Install typescript-eslint

```bash
npm install --save-dev eslint @eslint/js typescript typescript-eslint
npx eslint . or npm run eslint
```
